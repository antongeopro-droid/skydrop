SKYDROP

Jump from the airship, loot a town, build and edit your way up, and be the last one standing on the island.

DOWNLOAD Windows
Free · Windows 10/11, 64-bit · DirectX 12 graphics card · single player vs. bots

FEATURES

Airship drop

Ride the airship over a big island, skydive, pop your glider and land wherever you want.

Build & edit

Walls, floors, ramps and cones in wood, brick and metal. Edit windows, doors, arches and stairs tile by tile.

Weapons

Assault rifles, pump and tactical shotguns, SMG, pistol and a bolt sniper with a zoomed scope.

Towns to loot

Cities, suburbs, farms, harbours and desert towns with furnished rooms, chests and floor loot.

Storm & bots

Up to 79 bots fight it out while the storm closes in. Skirmish, solo and mega drop modes.

Lobby

Battle pass, item shop, locker with outfits, back blings, pickaxes, gliders and emotes. Coins are earned by playing.

HOW TO PLAY

  1. Click Download and save the zip (about 1–2 GB).
  2. Right-click the zip → Extract All… (don't run it from inside the zip).
  3. Open the extracted folder and double-click Skydrop.exe.
  4. If Windows shows "Windows protected your PC", click More info → Run anyway. The game isn't code-signed, which is normal for small indie builds.

If it asks for the DirectX / Visual C++ runtime the first time, run Engine\Extras\Redist\en-us\UEPrereqSetup_x64.exe from the game folder. Settings (graphics, sound, key bindings) are in the lobby's Settings tab or the in-game Esc menu.
